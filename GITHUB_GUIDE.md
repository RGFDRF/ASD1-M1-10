# Publikacja i oddanie

1. Zaloguj się do swojego konta GitHub w przeglądarce.
2. Utwórz repozytorium ASD1-M1-10. Prowadzący musi mieć dostęp.
3. Wgraj zawartość tego folderu, zachowując katalogi js, tests, results i assets. Sam ZIP w repozytorium nie zastępuje rozpakowanego kodu.
4. Sprawdź obecność README, index.html, testów i obu PDF-ów.
5. W Dzienniku dołącz pakiet aplikacji z kodem/testami, prezentację oraz documentation.pdf. Link do repozytorium wpisz osobno w polu „Linki”.
6. Sprawdź potwierdzenie zapisania pracy. Samo przygotowanie plików nie oznacza oddania.

Wymagane logowanie do konta; hasła wpisuj samodzielnie, bez podawania ich w rozmowie.
